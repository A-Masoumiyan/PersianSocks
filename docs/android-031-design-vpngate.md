# Android 0.31.0 / versionCode 49

Implements approved design #1 with native Android views: charcoal/teal wordmark, power/state card, always-visible Kill Switch toggle and app scope, All/SOCKS5/VPN Gate selector, country/sort, compact selectable server cards with favorites, fixed quick scan/refresh and bottom navigation. Existing detailed tests and routing settings remain in the drawer and server context menu. ChatGPT scope is a real checked control with selected styling and explicit accessibility ON/OFF; disabling restores the preceding policy. Errors remain visible and open a selectable/copyable report.

VPN Gate uses one isolated OpenVPN process under the existing VpnService, with a private UID-checked Android management socket and SCM_RIGHTS descriptors. Physical sockets are protected and bound before use. Server TLS is mandatory; directory options are rebuilt from bounded inline credentials/CA and allowlisted transport/crypto settings. No downloaded script, plugin or executable is accepted. A hard initial deadline and bounded retry policy prevent indefinite startup. The native binary for each of four ABIs is hash-pinned, kept unchanged in packaging and independently audited in the signed APK.

The official CSV API is preferred. A fallback mirror is resolved through a small index, immutable commit and exact file length/SHA-256; failed refresh preserves the cache. Directory nodes do not enter the healthy index until real HTTPS verification over the established VPN succeeds. Eight bounded TCP workers measure only port reachability; UDP profiles require a real connect test. A port result is not advertised as a verified VPN. No country-wide address sweep is performed. Up to three directory alternatives are eligible after a selected VPN Gate server fails, bounded by the existing overall failover policy.

OpenVPN supports ALL/selected-app/ChatGPT UID routing. Domain routing is explicitly refused for OpenVPN rather than silently broadening scope. Existing SOCKS domain routing remains available. IPv4 and IPv6 default routes are captured for the selected UIDs; missing IPv6 transport remains blocked. Guard TUN descriptors survive engine termination. During required address/interface changes, the retired TUN is held until Android publishes the new interface. The unchanged SOCKS startup reuses its existing guard interface.

VPN Gate's operators can log IP addresses and connection metadata. Its privacy note is available in server details and About. Native dependency notices are packaged; complete corresponding OpenVPN/dependency source archives and the build scripts accompany the release.

Validation: host transport/policy/parser suites; native-view layout/state unit tests in Persian and English at 320/412 dp; deterministic emulator tests for JNI startup/guard and a local OpenVPN TLS server, protected upstream descriptor, actual HTTP traffic through TUN, retained guard and release. These are fixture checks, not proof of reachability from every Iranian ISP or physical Android handset.
