PersianSocks Windows 0.1.0
مناسب ویندوز ۱۰ و ۱۱، نسخهٔ ۶۴ بیتی x64

اجرا:
۱. فایل ZIP را کامل با Extract All استخراج کن؛ برنامه را از داخل ZIP اجرا نکن.
۲. PersianSocks.exe را اجرا کن و درخواست Administrator ویندوز را تأیید کن.
۳. رابط در پنجرهٔ Microsoft Edge باز می‌شود؛ اگر Edge پیدا نشود مرورگر پیش‌فرض باز می‌شود.
۴. «دریافت لیست» را بزن؛ سپس «اسکن از ابتدا» را بزن.
۵. یک پروکسی سالم انتخاب کن و دکمهٔ پاور را بزن.
۶. برای خروج کامل، از تنظیمات «قطع اتصال و خروج از برنامه» را بزن.

این بسته پرتابل است؛ نصب Go، Python، Java یا دانلود جداگانهٔ موتور لازم نیست.
پوشهٔ bin باید کنار PersianSocks.exe باقی بماند. sing-box و Wintun داخل همین پوشه‌اند.
اجرای دوبارهٔ EXE، رابط نسخهٔ در حال اجرا را دوباره باز می‌کند.
بستن پنجرهٔ رابط فوراً برنامه را نمی‌بندد؛ پس از ۱۰ دقیقه بدون ارتباط رابط، برنامه بسته و تونل قطع می‌شود.

قابلیت‌ها:
- منابع نسخهٔ اندروید ۰.۱۶.۰: ۲۳ منبع SOCKS5، HTTP و HTTPS با مسیر جایگزین، نمونه‌های داخلی و ورود دستی.
- تشخیص سلامت با HTTPS واقعی و گواهی معتبر؛ پاسخ TCP یا SOCKS به‌تنهایی نتیجهٔ سالم محسوب نمی‌شود.
- تست صفحات عمومی تلگرام، یوتیوب و اینستاگرام و تا ۸ مقصد HTTPS دلخواه.
- فیلتر سرویس، نوع، محدودیت پینگ و مرتب‌سازی روی صفحه؛ تنظیمات در سایدبار.
- تست اتصال و سرعت مستقل؛ سرعت بر حسب MB/s و مصرف حداکثر ۲۰ مگابایت در هر تست سرعت.
- پیشرفت قابل ادامه، حذف نتایج نامعتبر، کش پایدار، کشور آفلاین و خروجی فایل سالم‌ها.
- اتصال سراسری TUN با sing-box؛ اسکن به کارت شبکهٔ اصلی و DNS ثبت‌شدهٔ همان کارت متصل است.
- دکمهٔ پاور با انیمیشن انتظار؛ مراحل داخلی اتصال به‌صورت متن نمایش داده نمی‌شوند و خطا نمایش داده می‌شود.
- تعویض خودکار اختیاری پس از دو شکست متوالی، با انتخاب پروکسی مناسب همان مقصد.

داده‌ها در %APPDATA%\PersianSocks نگهداری می‌شوند. هیچ گزارش یا کانفیگی خودکار ارسال نمی‌شود.
اگر شبکه عوض شد، اسکن و اتصال را متوقف کن و «شناسایی دوبارهٔ شبکه» را بزن.
پروکسی‌های این نسخه IPv4 هستند. SOCKS5 و HTTP خودشان رمزنگاری اضافه نمی‌کنند؛ گواهی HTTPS مقصد بررسی می‌شود.
نتیجهٔ سرویس، دسترسی به صفحهٔ عمومی را نشان می‌دهد و تضمین ورود به حساب، تماس، پخش رسانه یا دوام پروکسی نیست.
این نسخه کلاینت SOCKS/HTTP است و لینک VLESS، VMess، Trojan یا subscription مربوط به V2Ray وارد نمی‌کند.

اعتبارسنجی:
هسته و رابط در محیط لینوکس آزمایش شدند؛ اجرای تونل Wintun، دسترسی Administrator، تنظیم مسیر سیستم و IP_UNICAST_IF
روی ویندوز واقعی در این محیط آزمایش نشده‌اند. این بسته نسخهٔ اولیهٔ ویندوز است.
تست‌ها: HTTPS روی سه نوع پروکسی، رد گواهی نامعتبر و پاسخ ۴۰۳، لغو سوکت، ذخیره و ادامهٔ پیشرفت خارج از ترتیب،
فیلتر پینگ، کنترل دسترسی API محلی، پیکربندی قابل قبول sing-box، نگهداری ۵۰ هزار نتیجه و بررسی همزمانی.
