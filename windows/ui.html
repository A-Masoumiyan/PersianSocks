تنظیمات و ابزارها

اسکن

صفر یعنی تمام لیست. تعداد کارگر پیش‌فرض: ۱۲.

منابع دلخواه

هر خط: نوع پروکسی و لینک HTTPS لیست. منابع داخلی هم حفظ می‌شوند.

مقصدهای تست دلخواه

حداکثر ۸ نشانی HTTPS. نتیجهٔ سرویس فقط دسترسی به صفحهٔ عمومی آن را تأیید می‌کند.

شبکه و فایل‌ها

گزارش منابع


دربارهٔ اتصال
موتور sing-box و Wintun همراه برنامه‌اند. اتصال سراسری با دسترسی Administrator اجرا می‌شود. ترافیک اسکن روی کارت شبکهٔ اصلی باقی می‌ماند.
پروکسی عمومی تضمین دوام یا سرعت ندارد. TLS مقصد اعتبارسنجی می‌شود؛ SOCKS5 و HTTP خودشان رمزنگاری اضافه نمی‌کنند. تست سرعت حداکثر ۲۰ مگابایت مصرف دارد.
برای قطع تونل و بستن کامل برنامه از دکمهٔ زیر استفاده کن. اگر صفحه بیش از ۱۰ دقیقه پاسخ ندهد، برنامه خودکار بسته و تونل قطع می‌شود.




ورود پروکسی
هر خط یک IP:PORT یا لینک socks5://، http:// یا https://. فایل متنی هم قابل انتخاب است.


ارتباط با برنامه قطع شد. دوباره PersianSocks.exe را اجرا کن.
